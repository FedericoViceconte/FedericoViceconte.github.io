# Portfolio de Federico Viceconte

Sitio personal con mis proyectos, demos, descargas y contacto: **https://federicoviceconte.github.io/**

Es una página estática en HTML, CSS y JavaScript, sin dependencias ni pasos de compilación. GitHub Pages la
publica desde la rama `main` en cada cambio.

| Archivo | Contenido |
| --- | --- |
| `index.html` | Presentación, proyectos destacados, proyectos en equipo, tecnologías y contacto |
| `estilos.css` | Diseño y versión para celulares |
| `img/` | Capturas de los proyectos, ícono e imagen para compartir el enlace |

Para verlo en local, abrí `index.html` en el navegador.
